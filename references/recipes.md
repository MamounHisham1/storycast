# Script recipes

Structures that produced working episodes. Word counts assume ~2.6 words/second
of TTS narration; vertical shorts live at 120–150 words (50–70s).

## The cold-open hook

The first sentence must create a question the viewer needs answered. Greetings
and setup kill retention.

- "In 1872, a ship was found sailing alone across the Atlantic." (mystery: found *how*? alone *how*?)
- "There is an animal that sleeps for three years." (absurd fact)
- "Your brain does something strange in the seven minutes before you sleep." (relatable + strange)

Bad: "Today we're going to talk about the Mary Celeste." — never announce.

## The escalation

After the hook: 3–5 short beats, each adding one new fact or raising the stakes.
Short sentences. One idea per sentence — the narration is TTS, and commas-heavy
prose makes synthetic voices rush.

## The honest landing

For true-story content: state plainly what is known and unknown. "After 150
years… no one knows" outperforms a forced explanation — and it's honest. Never
invent a resolution for a mystery.

## The call-to-action

Last line, every episode, every language: one ask, tied to the format.
"Follow for a new true story, every night." Localize meaning, not words.

## Multi-language rules

- One script per language, written **natively**, not machine-translated from the
  other. The beats match; the sentences don't have to.
- Arabic: write fully vocalized (with tashkeel). TTS mispronounces bare Arabic;
  vocalized text fixed it. Keep a plain variant only if a voice sounds
  over-articulated.
- Pacing differs per voice: the same 125-word script ran 22s in one Arabic voice
  and 30s in another. If a channel needs calm pacing, favor the naturally slower
  voice over artificially slowing a fast one.

## Episode math

- 120–150 words ≈ 50–70s narration ≈ +2s tail = final cut length.
- Stock-footage pool: 15–20 clips at 3s each covers a 60s episode with reuse.
- One concept list can feed weeks: each concept = one episode in N languages.
